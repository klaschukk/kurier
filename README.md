# klaschuk — PWA для курьера доставки (бета)

Статичное приложение без сервера: `public/` (index.html, app.js, style.css, sw.js, manifest.json, icons/).
Данные хранятся только в localStorage телефона (`kurier.v1`); бэкап — JSON-файл из вкладки «Сервис».

Вкладки: Смена (чек-лист, таймер, доставки, наличка, батарея на ходу) · Батарея (вольтаж → % → км,
порог «домой», время зарядки, свой реальный расход по сменам) · Деньги (чистыми после доли за профиль,
€/ч по окнам дня, наличка для Wolt, расходы) · Цель (накопления, промежуточная цель, прогноз даты) ·
Сервис (обслуживание по км/дням, настройки, бэкап).

## Нормальный хостинг
1. A-запись `klaschuk.otto-web.online` → `159.195.196.170` (там же, где DNS otto-web.online).
2. `sudo bash /home/kurier/deploy/install.sh` — vhost + Let's Encrypt, проверяет DNS перед стартом.
После этого: офлайн работает, предупреждения о сертификате нет. Данные со старого адреса (:8092)
не переедут сами — перед переходом «Бэкап» на старом, «Загрузить» на новом.

## App Store
Не бесплатно: Apple Developer Program $99/год, оформить можно с 18 лет (или на взрослого).
Обёртку сайта (Capacitor) Apple часто отклоняет по правилу 4.2, если нет «нативной» пользы.
До этого PWA через Safari → «На экран Домой» даёт то же самое бесплатно.

## Изменения
При правке файлов подними `VERSION` в `sw.js` и `?v=` в index.html, иначе телефон покажет старый кэш.
